工作记忆和认知负荷是什么关系？为什么我在学复杂算法的时候总是感觉脑子不够用？
刚刚
学

你感受到的"脑子不够用"，正是认知负荷理论研究的核心现象。工作记忆是人在执行认知任务时临时保存并操作信息的系统，而认知负荷则衡量的是当前任务对工作记忆的压力大小。

关键概念
Working Memory（工作记忆）
人在执行认知任务时临时保存并操作信息的系统。容量有限，持续时间短，是所有复杂认知活动（理解、推理、学习）的瓶颈。

认知负荷理论由教育心理学家 John Sweller 于 1980 年代提出。该理论区分了三种负荷类型：

内在负荷（Intrinsic Load）：由学习材料本身的复杂度决定，无法通过教学设计降低。例如学习递归算法时必须理解的状态空间。

外在负荷（Extraneous Load）：由不良教学设计引入的额外认知负担。例如一个设计混乱的流程图迫使学习者在脑中反复来回对照。

相关负荷（Germane Load）：用于构建心智模型和图式的工作记忆投入——这是学习真正需要的负荷。

原文 Sweller · P24 Anderson · P112 +2
Working memory has limited capacity and duration. Cognitive load theory contends that instructional designs that impose a high extraneous cognitive load will be less effective than designs that reduce this load, as the limited capacity of working memory will be consumed by activities that are unrelated to schema acquisition.
Sweller, J. · 《Cognitive Load Theory》 · P24 · §2.1 工作记忆容量与教学设计
Anderson, J.R. · 《Cognitive Psychology and Its Implications》 · P112 · §4.3 Working Memory Capacity

举一个具体的例子。假设你正在学习一个需要同时记住 7 个中间变量的算法实现。这 7 个变量都会占用你的工作记忆容量（Miller 的 7±2 法则）。如果这 7 个变量之间的依赖关系还不清晰，你的工作记忆会同时承担：

① 记住每个变量的当前值（内在负荷）
② 理清变量之间的依赖顺序（外在负荷，因为不够清晰）
③ 试图理解整体算法意图（相关负荷）

当①+②接近或超过工作记忆容量时，③就会被挤出——你会感觉"看了但没理解"。

认知负荷模型
Total Load = Intrinsic + Extraneous + Germane
有效学习 = 降低 Extraneous ↑ · 保证 Germane ↑
