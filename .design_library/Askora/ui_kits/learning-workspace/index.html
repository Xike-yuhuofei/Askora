请用一句话解释什么是过拟合？
学习助手 · 刚刚
过拟合是指模型在训练数据上表现很好，但在未见数据上泛化能力差的现象——它「记住」了训练样本的噪声而非背后的规律。
你 · 刚刚
那如何避免过拟合？给我几个方法。
学习助手 · 刚刚
常见方法包括：增加训练数据、正则化（L1 / L2）、早停、Dropout，以及简化模型结构。其中正则化与早停最常用，我可以结合你的讲义第 3 章详细展开。
