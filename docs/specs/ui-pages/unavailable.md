# 不可用兜底页（`/learning/:kind/unavailable`、not-found）

> **页面职责**：当用户明确请求某功能但当前空间/系统不支持时，诚实告知并给出可达退路；404 亦复用本兜底。
> **对应契约**：`INT-STATE-002`（诚实状态）、`UI-ROUTE-006`（不可用兜底）、`EXP-IA-001`
> **现状基准**：`apps/frontend/src/pages/Unavailable.jsx`（已中文；「返回今天」需改「返回欢迎」，见 §6）

---

## 1. 页面目标

1. 明确说明「为什么不可用」与「当前有什么可用替代」，不给假按钮。
2. 提供最少一个真实可达的退路（返回欢迎/资料库）。
3. 区分 kinds：goals / path / library / evidence / activity / not-found。

**不做什么**：不把不可用伪装成 loading 或成功；不显示无意义的禁用入口墙。

## 2. 布局区划

```
┌──────────────────────────────────────────────┐
│ 图标（按 kind）+ h1「暂不可用」+ 原因说明             │
├──────────────────────────────────────────────┤
│ 可用替代（1~2 个真实入口）· [返回欢迎 · primary]       │
└──────────────────────────────────────────────┘
```

## 3. 元素清单

| # | 元素 | 类型 | 文案 | 交互语义 | 层级 | 组件/Token | 状态 |
|---|---|---|---|---|---|---|---|
| UN-01 | 图标 | icon（按 kind） | goals/path/library/evidence/activity 对应 icon；not-found 用 Compass | — | — | 装饰 | — |
| UN-02 | 主标题 | 文本 h1 | 暂不可用 / 页面不存在 | — | — | text-primary | — |
| UN-03 | 原因说明 | 文本 | kind 化说明，如「当前空间还没有可用的学习路径」「这个页面不存在」。 | StatusFeedback | — | text-secondary | 诚实 |
| UN-04 | 可用替代 | 链接 | 前往资料库 / 查看学习证据 | Navigation | — | Link | 仅列真实可达 |
| UN-05 | 返回 | 按钮 | 返回欢迎 | Navigation（Primary） | Primary | Button primary | — |
| UN-06 | 错误提示 | 文本 | 若由错误引起：加载失败，请重试。 | StatusFeedback | — | 文本 | ERROR |

## 4. 状态矩阵

| 区域 | LOADING | EMPTY | READY | ERROR |
|---|---|---|---|---|
| 兜底页 | 正在确认可用性… | — | 不可用说明+退路 | 加载失败，请重试。 |

## 5. 无障碍

| # | 要求 |
|---|---|
| A-01 | 图标 `aria-hidden`；说明为真实文本。 |
| A-02 | 退路链接/按钮顺序：返回欢迎优先；`role="alert"` 用于错误原因。 |

## 6. 禁止事项与现状 GAP

| GAP | 处理 |
|---|---|
| 「返回今天」 | 改为「返回欢迎」（被冻结的「今天」心智，`EXP-IA-001`）。 |
| 可用替代 | 只列真实可达入口，不得为占位（现状正确）。 |

禁止：不可用页显示伪造成功/加载；把不可用状态当成用户错误（`INT-STATE-001`）。
