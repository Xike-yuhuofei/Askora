# 空间管理（`/spaces`）

> **页面职责**：空间的创建、浏览、重命名与进入。单一入口页承载 CRUD 操作。**Navigation 进入不产生业务写入；只有提交正式 Workspace create/rename command 才显示成功。**
> **对应旅程**：`EXP-JOURNEY-004`（建立或扩充空间）
> **对应契约**：`UI-COURSE-005`、`UI-NAV-006`、`UI-DS-COMP-013`
> **现状基准**：`apps/frontend/src/pages/WorkspaceManage.jsx`（空间列表 + 新建 + 重命名 + 进入）

---

## 1. 页面目标

1. **创建**：提交一个空间名，创建真实 `Workspace`。
2. **浏览**：展示用户拥有的所有空间列表，诚实表达状态。
3. **重命名**：在列表中直接重命名空间，提交 rename command。
4. **进入**：点击空间卡片进入该空间。

**不做什么**：不删除空间（v1 只支持创建/重命名，删除后续迭代）；不要求确认目标/计划；不自动开始对话；不用 frontend/localStorage 冒充创建成功。

## 4. 状态矩阵

| 区域 | LOADING | EMPTY | READY | PARTIAL | ERROR |
|---|---|---|---|---|---|
| 空间列表加载 | 骨架屏 | 空态 | 列表渲染 | 部分加载 | 「无法读取空间列表」+ 重试 |
| 创建空间 | 表单 LOADING | — | 成功 → 刷新列表 | — | 「无法创建空间」+ 重试 |
| 重命名 | 按钮 LOADING（单 flight） | — | 名称更新 | — | 「无法重命名」+ 恢复原名 |

错误三要素：发生了什么 → 数据是否安全 → 现在能做什么。

## 5. 交互流程

### 5.1 创建空间
1. 用户点击「+ 新建空间」
2. 弹出/展开内联表单（名称输入 + 取消 + 创建）
3. 输入名称 → 提交 → 调用 `createWorkspace` API
4. 成功：关闭表单、刷新列表、可选进入新空间
5. 失败：显示错误，保留输入允许重试

### 5.2 重命名空间
1. 用户点击卡片上的「重命名」
2. 名称变为可编辑输入框（原值预填）
3. 编辑名称 → 提交 → 调用 `renameWorkspace` API
4. 成功：名称更新为新值
5. 失败：恢复原名 + 显示错误

### 5.3 进入空间
1. 用户点击「进入」或卡片主体
2. 导航到 `/courses/:workspace_id`

## 6. 无障碍

| # | 要求 |
|---|---|
| A-01 | 空间卡片 `<article>` 或列表语义；每个操作按钮有真实 label。 |
| A-02 | 重命名时输入框有 `<label>`；`aria-invalid` + `aria-describedby` 关联错误。 |
| A-03 | 创建/重命名按钮 pending 时 `aria-busy`；提交成功后 focus 合理落点。 |
| A-04 | 错误 `role="alert"`，live 播报。 |
| A-05 | 键盘可达：Tab 遍历所有卡片操作，Enter/Space 触发操作。 |

## 7. 禁止事项

- 提交前 Navigation 不产生业务写入（`UI-NAV-006`）。
- 不自动开对话/创建 Session/Goal（`EXP-JOURNEY-004`）。
- 不预填「默认空间」名称；不做 frontend-only success（`INT-STATE-001`）。
- 成功状态只来自 Platform Workspace Registry command result（`UI-COURSE-002`）。
- 不展示目标管理、计划确认等主路径外步骤。
- v1 不支持删除空间（需独立 `deleteWorkspace` API + 二次确认，后续迭代）。
- 不允许空名称或纯空白；名称长度限制 1-120 字符。

## 8. API 依赖

| 操作 | 方法 | 端点 | 说明 |
|---|---|---|---|
| 列表 | GET | `/workspaces` | 获取用户所有空间 |
| 创建 | POST | `/workspaces` | 创建新空间（当前已有） |
| 重命名 | PATCH | `/workspaces/:id` | 更新空间 display_name（本次新增） |
| 进入 | — | 路由跳转 | `/courses/:workspace_id` |
