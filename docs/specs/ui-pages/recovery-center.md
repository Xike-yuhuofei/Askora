# 错误恢复中心（`/recovery`，工具/Utility 页）

> **页面职责**：集中展示空间级待处理问题与可执行恢复动作；动作按钮及其可行状态来自后端（不在前端臆造）。
> **对应契约**：`EXP-IA-001`（Settings/Recovery 为 Utilities）、`UI-SET-004`、`INT-STATE-001/002`、`RECOVERABLE` 状态
> **现状基准**：`apps/frontend/src/pages/RecoveryCenter.jsx`（已中文、issue cards、动作来自后端）

---

## 1. 页面目标

1. 以诚实状态列出每个问题（原因、影响、能否恢复），不伪装 READY。
2. 提供后端给出的动作按钮；无动作时说明「暂无可用操作」。
3. 恢复完成后从列表移除；失败保留并允许重试。

**不做什么**：不在前端猜测/伪造恢复动作；不自动执行破坏性恢复。

## 2. 布局区划

```
┌──────────────────────────────────────────────┐
│ eyebrow「设置 · 本地恢复」+ h1「错误恢复中心」          │
├──────────────────────────────────────────────┤
│ h2 待处理问题                                  │
│   · issue card：类型 · 原因 · 影响 · [动作按钮]      │
│   · 空态：目前没有需要恢复的问题                      │
└──────────────────────────────────────────────┘
```

## 4. 状态矩阵

| 区域 | LOADING | EMPTY | READY | PARTIAL | ERROR |
|---|---|---|---|---|---|
| 问题列表 | 正在读取恢复中心… | 目前没有需要恢复的问题 | 问题卡片 | 部分可恢复 | 恢复中心暂时无法读取。+ 重试 |
| 单条恢复 | 正在恢复… | — | 恢复完成 | — | 恢复失败，请重试。 |

## 5. 无障碍

| # | 要求 |
|---|---|
| A-01 | 卡片状态非仅颜色；动作按钮有语义 label。 |
| A-02 | 恢复结果 `role="status"`；错误 `role="alert"`。 |

## 6. 禁止事项

- 不在前端臆造恢复动作或可行状态（动作必须来自后端，现状正确）。
- 不自动执行破坏性恢复；失败不伪装成功（`INT-STATE-002`）。
