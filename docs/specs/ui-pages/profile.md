# 个人档案（`Profile`，**退役页**）

> **页面职责**：**无**。该 legacy 页面展示「掌握知识点」「学科掌握度」，违反诚实数据与「无掌握度」原则，且已不可达。
> **对应契约**：`EXP-IA-004`、`UI-ROUTE-004`（legacy 清理）、`INT-STATE-002`（真实/已规划 帮助状态；不伪造掌握度）
> **现状基准**：`apps/frontend/src/pages/Profile.jsx`（legacy mastery 展示）

---

## 1. 处置决定

**建议退役：删除组件与路由引用；不为其做元素规划。** mastery/学科掌握度是已冻结规范明确禁止的伪造成就形态。

## 2. 现有元素（退役清单）

| 元素 | 现有内容 | 违反契约 | 处置 |
|---|---|---|---|
| 掌握知识点 | 知识点列表+掌握度 | 无依据成就；图谱心智（`EXP-IA-004`） | 删除 |
| 学科掌握度 | 学科级百分比 | 伪造掌握度（`INT-STATE-002`） | 删除 |

## 3. 替代

用户查看学习进展 → 学习证据（evidence.md）的「当前判断」；查看历史 → 历史记录（history.md）。

## 4. 禁止事项

- 恢复 mastery/掌握度 UI（`INT-STATE-002`）。
- 把证据/判断渲染成百分比或星级成就。
