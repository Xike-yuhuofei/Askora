# 资料去向（`MaterialDestination`，上传/加入后弹层）

> **页面职责**：资料处理完成后，让用户决定去向——**加入已有空间 / 当场新建并加入 / 马上开始学习**。是 `EXP-JOURNEY-001` 与 `EXP-JOURNEY-004` 共用的「现在学吗」弹层。
> **对应旅程**：`EXP-JOURNEY-001`（用资料开始学习）、`EXP-JOURNEY-004`（往已有空间加资料）
> **对应契约**：`UI-COURSE-002`、`UI-COURSE-005`、`EXP-PARSE-001`
> **现状基准**：`apps/frontend/src/components/MaterialDestination.jsx`（已中文、已空间语义、结构正确）

---

## 1. 页面目标

1. 诚实呈现资料处理状态（等待 / 处理中 / 完成 / 失败 / 未通过 / 已隔离）。
2. 处理完成后给出二选一主路径：**加入学习空间** 或 **马上开始学习**；也允许**稍后决定**。
3. 「马上开始学习」= Action：自动建空间、放入资料、开首段对话（`EXP-JOURNEY-001`）。缺模型时说明还缺模型，不用 mock 冒充。

**不做什么**：处理未完成时不允许开始有依据的学习；不把「仅本机解析」说成模型已读懂全书（`EXP-PARSE-001`）。

## 2. 布局区划

```
┌──────────────────────────────────────────┐
│ eyebrow「资料去向」+ h2 资料标题                │

├──────────────────────────────────────────┤
│ h3 加入学习空间                               │
│   已有空间 [select]                          │
│   或新建空间名称 [input]                       │
│   [加入所选空间] [新建并加入]                    │
├──────────────────────────────────────────┤
│ h3 马上开始学习                               │
│   说明：自动建空间并放入这份资料                   │
│   [马上开始学习 · primary]                    │
├──────────────────────────────────────────┤
│ [稍后决定]（关闭弹层，资料留在资料库）              │
└──────────────────────────────────────────┘
```

## 4. 处理状态文案（`StatusFeedback`，`UI-DS-FB-*`）

| 状态 | 文案 |
|---|---|
| 等待处理 | 资料已保存，正在等待处理。 |
| 处理中 | 资料正在处理，还不能加入空间。 |
| 处理完成 | 处理完成。选择加入已有空间，或马上开始学习。 |
| 处理失败 | 处理失败，不能开始有依据的学习。 |
| 未通过检查 | 资料未通过检查，不能加入空间。 |
| 已隔离 | 资料已隔离，不能加入空间。 |
| 无空间可选 | 还没有空间。可以当场新建，或使用马上开始学习。 |
| 仅本机解析 | 已完成本机解析。模型可用时可「用模型再解析」（此开关在设置）。 |

| 区域 | LOADING | EMPTY | READY | PARTIAL | STALE | ERROR |
|---|---|---|---|---|---|---|
| 空间列表 | 「正在读取空间…」 | 「还没有空间…」 | 可选空间 | — | — | 「无法读取空间」+ 重试 |
| 加入空间 | 按钮 LOADING | — | 加入成功 → 关闭并提示「资料已加入空间。」 | — | — | 「无法加入空间」；不显示占位 |
| 马上开始 | 按钮 LOADING | — | 进入对话 | 模型缺失时说明还缺模型 | — | 「无法马上开始学习」 |
| 新建并加入 | 按钮 LOADING | — | 成功 → 进入空间 | — | — | 「无法创建并加入空间」 |

## 7. 禁止事项

- 处理未完成 / 失败时不允许「马上开始学习」进入有依据的学习（`EXP-JOURNEY-004`）。
- 缺模型时不得用 mock 对话或假教师冒充学习（`EXP-PARSE-003`）。
- 「仅本机解析」不得表述为模型已读懂全书（`EXP-PARSE-001`）。
- 不得把本弹层做成每次上传必经的目标确认向导（`UI-WELCOME-001`）。
- 成功只来自 owner command result；不得 frontend/localStorage 冒充（`UI-NAV-006`）。
