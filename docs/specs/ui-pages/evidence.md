# 学习证据（`/learning/evidence`，兼容/上下文页）

> **页面职责**：在明确 user job 下查看某学习目标的学习证据（独立成功、延迟回忆、迁移证据、有效证据权重），以及基于证据的「当前判断」。只读审计页。
> **对应契约**：`UI-ROUTE-004`（evidence audit）、`INT-MAP-003`、`LEXP-015`、`UI-DATA-040`
> **现状基准**：`apps/frontend/src/pages/Evidence.jsx`（已中文、诚实「当前判断」）

---

## 1. 页面目标

1. 诚实展示「学习者模型」与证据来源：不做无证据的掌握度数值。
2. 当前判断是「暂定的、基于现有证据」，可随证据变化。
3. 空态不伪装（还没有足够的学习证据 ≠ 已掌握）。

**不做什么**：不输出 mastery 百分比/星级；不进入核心旅程；不从前端推断证据权重。

## 2. 布局区划

```
┌──────────────────────────────────────────────┐
│ eyebrow「学习者模型」+ h1「学习证据」                │
├──────────────────────────────────────────────┤
│ 事实网格：独立成功 / 延迟回忆 / 迁移证据 / 有效证据权重     │
│ 当前判断（状态标签 + 说明）                         │
├──────────────────────────────────────────────┤
│ h2 证据列表（条目：类型 · 来源活动 · 时间 · 结果）        │
│ 空态：还没有足够的学习证据                            │
└──────────────────────────────────────────────┘
```

## 4. 状态矩阵

| 区域 | LOADING | EMPTY | READY | PARTIAL | STALE | ERROR |
|---|---|---|---|---|---|---|
| 证据加载 | 正在读取学习证据… | 还没有足够的学习证据 | 事实网格+证据列表 | 判断「暂定」 | 证据版本过期提示 | 学习证据暂时无法读取。+ 重试 |

## 5. 无障碍

| # | 要求 |
|---|---|
| A-01 | 事实网格缺失项有「未设置/暂无」文本，非仅颜色。 |
| A-02 | 证据条目与查看动作独立 focus target；`role="status"` 用于判断更新。 |
| A-03 | 空态不是错误；`role="status"` 而非 alert。 |

## 6. 禁止事项

- 无「掌握度」百分比/星级/总分（现状诚实，保留）。
- 证据不足不得显示为已掌握；由导航/route 变化触发推断（`UI-ROUTE-005`）。
- 前端不得自行计算有效证据权重；权重仅来自 owner（`UI-DATA-003`）。
