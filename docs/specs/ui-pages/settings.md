# 设置（`/settings`，overlay 对话框）

> **页面职责**：空间级设置（对话框形态）——通用、数据管理、隐私与安全、危险操作。改动即保存；危险操作需二次确认。
> **对应契约**：`UI-SET-001~004`、`EXP-PARSE-002`（AI 增强资料解析）、`UI-DS-COMP-072`（Dialog）
> **现状基准**：`apps/frontend/src/pages/Settings.jsx`（已中文、分类清晰、危险操作有确认）

---

## 1. 页面目标

1. 在对话框内完成设置分类与即时保存（不改即不动，`UI-SET-001`）。
2. 危险操作（导出/删除）明确说明影响并需确认（`UI-SET-002/003/004`）。
3. 「用 AI 增强资料解析」toggle 诚实反映用途与隐私边界（`EXP-PARSE-002`）。

**不做什么**：设置不覆盖冻结规范；AI 解析增强不改变「解析文本必须可见、可核对」的诚实原则。

## 2. 布局区划

```
┌───────────────────────────────────────────┐
│ Dialog：h2「设置」 [关闭 ✕]                    │
├───────────────────────────────────────────┤
│ 通用（偏好项 rows）                            │
│ 数据管理（导出/导入/自动备份）                     │
│ 隐私与安全（AI 解析 toggle · 本地存储说明）         │
│ 危险操作（导出全部数据/删除空间/重置）               │
└───────────────────────────────────────────┘
```

## 4. 状态矩阵

| 区域 | LOADING | READY | SAVING | SAVED | ERROR |
|---|---|---|---|---|---|
| 设置加载 | 正在读取设置… | 设置项 | 保存中… | 设置已保存 | 设置暂时无法读取。+ 重试 |
| 导出 | 正在导出… | 可导出 | — | 导出完成 | 导出失败，请重试。 |
| 删除 | 正在删除… | 需确认 | — | 已删除 | 删除失败，请重试。 |

## 5. 无障碍

| # | 要求 |
|---|---|
| A-01 | Dialog focus 落入、焦点圈闭、Esc 关闭、`aria-modal`（`UI-DS-COMP-072`）。 |
| A-02 | toggle 有 label 与状态；切换立即保存时 `aria-busy`。 |
| A-03 | 危险操作二次确认 focus 管理；删除不可撤销说明随确认弹层。 |

## 6. 禁止事项

- AI 解析增强不得隐藏原始解析文本或伪造「已解析」（`EXP-PARSE-002` 诚实边界）。
- 危险操作不得单次点击直接执行；导出/删除必须可追踪、可确认。
- 设置改动不提示即静默失败（需 SAVED/ERROR 反馈）。
