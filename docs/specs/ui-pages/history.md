# 历史记录（`/learning/history`，兼容/上下文页）

> **页面职责**：只读查看某空间/目标的过去活动、已完成活动与已结束对话的序列。**非进展仪表盘**——不显示未来计划，不推断「接下来该做什么」。
> **对应契约**：`UI-ROUTE-004`（history audit）、`INT-MAP-003`、`UI-DATA-040`
> **现状基准**：`apps/frontend/src/pages/History.jsx`（已中文；空态文案引用「今天」需修复，见 §6）

---

## 1. 页面目标

1. 只读列出历史活动/对话，按时间倒序，带完成状态与结果摘要。
2. 已完成活动提供回看/续读入口（不自动 resume）。
3. 空态诚实：没有历史 ≠ 没有进度。

**不做什么**：不显示计划/路径；不做未来预测；不是核心旅程常驻页。

## 2. 布局区划

```
┌──────────────────────────────────────────────┐
│ eyebrow「只读历史」+ h1「历史记录」                 │
├──────────────────────────────────────────────┤
│ 过滤：全部 / 学习活动 / 对话                       │
│ h2 最近 30 天（历史条目：类型 · 标题 · 时间 · 状态）     │
│ 空态：还没有历史记录                               │
└──────────────────────────────────────────────┘
```

## 4. 状态矩阵

| 区域 | LOADING | EMPTY | READY | PARTIAL | STALE | ERROR |
|---|---|---|---|---|---|---|
| 历史加载 | 正在读取历史记录… | 还没有历史记录 | 条目序列 | 部分年份缺失 | 提示部分记录暂不可读 | 历史记录暂时无法读取。+ 重试 |

## 5. 无障碍

| # | 要求 |
|---|---|
| A-01 | 过滤控件语义化单选；条目与「回看」独立 focus target。 |
| A-02 | 空态为 status 非 alert；状态非仅颜色。 |

## 6. 禁止事项与现状 GAP

| GAP | 处理 |
|---|---|
| 空态文案引用「今天」 | 改为中性时间表达，如「完成学习活动后，这里会记录过程。」（移除被冻结的「今天」心智，`EXP-IA-001`）。 |
| 回看入口 | 不得在进入时自动 resume 活动（需显式按钮）。 |

禁止：在历史页显示未来计划/路径/预测（`UI-DATA-003`）；把对话轮次计数当作历史条目的顺序依据（`EXP-WSP-005`）。
