# v0.3.1 Rich Response Rendering Vertical Slice

> 状态：Frozen
> 实现入口：EXEC-014
> 范围：Markdown、GFM、KaTeX、typed cards、citation block、plain fallback

## 1. Objective

在不改变 v0.3 adaptive teaching semantics 的前提下，把 canonical `reply_text` 扩展为可持久化、可回退、可安全渲染的 `RenderPayloadV1`，并让普通响应、历史消息与 SSE final 使用同一 accepted payload。

## 2. End-to-End Path

```text
canonical reply_text / typed candidate
→ SYS08 render-payload/1.0 validation
→ RenderPayloadV1 + message.content fallback
→ dialog_messages durable JSON
→ HTTP/history/SSE final serialization
→ frontend RichMessage allowlist renderer
→ Markdown/GFM/KaTeX/Card/Citation UI
```

## 3. Scope

IN：

- versioned RenderPayloadV1；
- Markdown/GFM/math/card/citation blocks；
- deterministic text-to-MarkdownBlock baseline；
- nullable JSON migration；
- normal/history/SSE final compatibility；
- raw HTML/MDX/unsafe URL/remote image blocking；
- frontend typed renderer and automated tests。

OUT：

- arbitrary HTML/MDX；
- model-defined React components；
- interactive card commands；
- image/audio/video generation or hosting；
- card-driven policy/mastery/plan/review mutation；
- changes to six StrategyFamily or TeachingAction semantics。

## 4. Ownership and Migration

RenderPayload 是 SYS08-owned execution/presentation artifact，不建立第九 domain owner。`DialogMessage.content` 保持 required fallback；新增 `render_payload` nullable JSON。历史 rows 保持 null；new assistant completions 写 v1.0；user messages 默认 null。downgrade 删除新列，回退内容仍在 `content`。

## 5. Gate

只有以下全部满足时 slice 为 DONE：

- `RENDER-AC-001..008` 全部通过；
- no raw HTML/MDX/executable card path；
- unknown/invalid payload fallback；
- migration upgrade/downgrade/round-trip verified；
- normal/history/SSE final/replay equivalent；
- frontend production build passes；
- backend targeted/full applicable tests、Ruff、mypy pass；
- no TeachingAction/support/exposure ownership regression。
