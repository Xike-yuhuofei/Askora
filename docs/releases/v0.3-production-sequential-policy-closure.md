## Production Composition

```text
bootstrap decision   = TeachingContext.previous_teaching_action_ref is None -> deterministic TeachingPolicyKernel
second+ decision     = previous_teaching_action_ref exists -> exact previous TeachingAction + DecisionTrace
                     -> reconstructible SequentialPolicyState -> typed EvidenceSignal projection
                     -> SequentialTeachingPolicy (fixed decision_time) -> final PolicyDecision
```

- fail-closed：previous ref 存在但 action missing / trace missing / trace-action mismatch /
  scope mismatch / reconstruction ambiguous 时，报稳定 typed deterministic error，禁止 direct-kernel fallback。
- 唯一 production SYS05 composition boundary：`LearningOrchestrationFacade` 统一收口，Book-to-Learning 同路径。

## TeachingContext Hydration

从现有 canonical owner records 补齐（存在且 scope 匹配时装载，缺失保持显式 MISSING/empty）：

| field | canonical owner/source | availability |
|---|---|---|
| previous_teaching_action_ref | 上一 canonical TeachingAction | exact VersionedRef |
| recent_assessment_result_ref / correctness_score / assessment_confidence | 最近 accepted AssessmentResult | AVAILABLE / MISSING |
| error_type / diagnostic_confidence / needs_probe | canonical diagnosis | 存在即装载 |
| actual assistance / scaffold / hint / answer exposure history | canonical assistance records | 存在即装载 |
| independent / assisted success history | canonical attempt outcome | 存在即装载 |
| previous_action_outcome_refs | previous DecisionTrace/outcome refs | 存在即装载 |

禁止 MISSING → 0 / false / independent。所有进入 snapshot 的 owner facts 进入 source_refs 并参与确定性 fingerprint。
