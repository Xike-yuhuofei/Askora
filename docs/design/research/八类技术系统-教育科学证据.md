# 八类技术系统：教育科学证据

> 阶段：B｜统一研究资料库  
> 用途：为 Askora 第 4 章提供公共教育科学证据，避免八个系统重复解释理论。

## 1. 研究问题

1. 哪些学习科学原则具有较稳定、可重复的证据？
2. 哪些原则依赖学习阶段、任务类型或学习者已有知识？
3. 如何把“即时答对”与“长期保持、独立完成、迁移”区分？
4. Askora 应把哪些原则做成硬约束，哪些只作为策略候选？

## 2. 证据分级口径

- `学术共识`：多项高质量研究、系统综述或元分析方向一致。
- `研究证据`：存在同行评审研究支持，但效果依条件变化。
- `行业实践`：成熟产品或工程实践公开采用，不等同于因果教育效果。
- `Askora 设计选择`：基于证据与工程约束形成的系统决策。
- `实验性方案`：理论合理，但在 Askora 场景尚无足够验证。
- `研究者推断`：由公开证据推导出的架构含义，必须接受实验检验。

## 3. 核心结论

### 3.1 提取练习 / 测试效应

**结论**：让学习者主动从记忆中提取信息，通常比重复阅读更有利于延迟保持；测试不仅是测量工具，也可以是学习事件。

- 证据等级：`学术共识`
- 教育上有效：高
- 工程上成熟：高
- Askora 当前适用：高

Roediger & Karpicke（2006）显示，测试在延迟测验中可提高保持；Dunlosky 等（2013）将 practice testing 评为高效学习技术之一。Pan & Rickard（2018）的元分析进一步显示测试增强学习可以迁移到新情境，但迁移效果受到题型、材料和迁移距离影响。

**适用条件**：

- 必须要求真实提取，而不是让用户先看到答案再复述；
- 提示后的成功与无提示成功不能等权；
- 延迟测验比即时测验更能提供长期保持证据；
- 题目表面变化不等于真正迁移。

**Askora 设计含义**：

- `Attempt` 必须记录提示等级、是否看过答案、作答延迟和任务新颖性；
- `MasteryEstimate` 不应由单次即时正确直接跃迁为“掌握”；
- 教学策略应主动安排低提示/无提示提取，而不是持续解释。

### 3.2 间隔效应

**结论**：分散在时间上的学习通常优于等量集中练习；最优间隔与目标保持时长相关，而非存在一个固定天数。

- 证据等级：`学术共识`
- 教育上有效：高
- 工程上成熟：高
- Askora 当前适用：高

Cepeda 等（2006）对大量实验进行定量综述，确认 distributed practice 的稳健优势。近期针对医学教育等场景的系统综述仍支持间隔复习，但具体调度参数和长期效果受材料、任务与实施质量影响。

**Askora 设计含义**：

- 复习调度应以“目标保持概率/遗忘风险”而非固定日历间隔为核心；
- 4.7 可采用 FSRS/半衰期类模型，但调度算法属于工程实现，不应被描述为已证明适用于所有知识类型；
- 概念理解、程序性技能、开放式迁移任务不能简单等同于闪卡记忆。

### 3.3 交错学习

**结论**：交错练习在需要辨别类别、方法或策略的任务中常有优势，但并非所有材料均优于分块学习。

- 证据等级：`研究证据`
- 教育上有效：中高，依任务类型
- 工程上成熟：高
- Askora 当前适用：中高

Brunmair & Richter（2019）的元分析显示交错总体有正效应，但材料类型和相似性显著调节效果。

**Askora 设计含义**：

- 4.6/4.7 可把“相邻任务是否需要策略辨别”作为交错约束；
- 初学者尚未形成基本表征时，不应机械交错所有概念；
- 交错是计划约束，不是单独的掌握指标。

### 3.4 Worked Examples 与示例褪去

**结论**：对于缺乏先备知识的学习者，完整 worked examples 往往比直接大量解题更有效率；随着能力增长，应逐步减少支架，避免 expertise reversal。

- 证据等级：`学术共识` / `研究证据`
- 教育上有效：高，但强依学习者阶段
- Askora 当前适用：高

认知负荷研究与 worked-example 综述支持新手阶段降低不必要搜索成本；但当学习者已经掌握方案时，过多解释和完整示例会变成冗余。

**Askora 设计含义**：

- 4.5 必须让提示/示例强度依 LearnerState 变化；
- TeachingAction 应显式包含 scaffold_level；
- 不能把“讲得更详细”默认等同于“教得更好”。

### 3.5 认知负荷控制

**结论**：工作记忆容量有限，教学设计应减少与目标无关的额外负荷，并根据已有知识控制一次交互的元素数量与推理跨度。

- 证据等级：`研究证据`
- 教育上有效：中高
- Askora 当前适用：高

**局限**：认知负荷不是一个可直接由 LLM 精确读出的隐藏变量；主观量表、行为表现、任务结构只能形成估计。

**Askora 设计含义**：

- 内容侧的 intrinsic complexity 与“对特定用户的预测负荷”必须分离；
- 4.2 的 EvidenceBundle 应有上下文预算；
- 4.5 控制一次 TeachingAction 的信息量与提示跨度；
- 不能把 token 数简单当作认知负荷。

### 3.6 形成性评价与反馈

**结论**：反馈可以显著影响学习，但效果取决于反馈指向任务、过程还是自我调节，以及反馈是否给出可执行的下一步；单纯赞美或答案揭示不等价于有效反馈。

- 证据等级：`学术共识` / `研究证据`
- 教育上有效：高但异质性大
- Askora 当前适用：高

Hattie & Timperley（2007）强调有效反馈需要回答“目标是什么、当前在哪里、下一步是什么”。Black & Wiliam（1998）表明形成性评价具有重要潜力，但实际收益依赖教学反馈闭环的实现。

**Askora 设计含义**：

- 4.4 产生诊断证据；4.5 决定反馈策略；4.8 负责表达，三者不得合并成一次自由生成；
- “点赞/满意”属于体验信号，不应直接进入 MasteryEstimate；
- 反馈应优先指出错误位置/类型和下一步，而非立即给完整答案。

### 3.7 脚手架与最近发展区

**结论**：根据学习者能力提供暂时性支架，并随着能力提高逐渐撤除，符合教学理论和大量实践；但“最近发展区”不能被软件当作可直接观测的精确数值。

- 证据等级：`研究证据` + `研究者推断`
- Askora 当前适用：高（原则），中（精确建模）

**Askora 设计含义**：

- 提示等级必须可记录、可递增、可撤除；
- 不建立一个伪精确 `zpd_score`；
- 用任务成功率、提示依赖、前置掌握和错误类型构成可审计的 TeachingContext。

### 3.8 Productive Failure

**结论**：在部分概念学习场景中，让学习者先尝试生成/探索、再进行结构化讲解，可改善概念理解与迁移；这不是“让用户一直失败”。

- 证据等级：`研究证据`
- 教育上有效：中，条件敏感
- Askora 当前适用：中

Kapur 等关于 Productive Failure 的研究支持“先生成—后整合”的教学序列，但依赖任务设计、先备知识、失败后的 consolidation。

**Askora 设计含义**：

- 只作为 4.5 的候选 TeachingStrategy；
- 需要失败次数、挫败信号、时间预算等安全退出条件；
- 不得由 RL 为探索长期故意制造无界失败。

### 3.9 Desirable Difficulties

**结论**：增加适当的提取难度、间隔、交错和生成要求，可能提高长期学习，但“困难”只有在最终促进保持/迁移时才是 desirable。

- 证据等级：`研究证据`
- Askora 当前适用：高（约束思想）

**设计含义**：即时表现下降不一定意味着教学策略变差；在线评价必须结合延迟保持和迁移。

### 3.10 元认知与自我调节学习

**结论**：目标设定、监控、反思和策略选择等自我调节支持总体上有积极证据，但效果依赖提示质量与学习者执行。

- 证据等级：`研究证据`
- Askora 当前适用：中高

Donker 等（2014）、Jansen 等（2019）等综述/元分析显示自我调节策略教学具有总体正效应；计算机环境中的元认知提示也存在积极证据，但不能无限增加干预频率。

**Askora 设计含义**：

- Open Learner Model、目标确认、阶段性反思值得支持；
- 用户应能纠正系统对目标与状态的判断；
- 反思提示属于 LearningActivity，而非对所有会话固定追加。

### 3.11 知识迁移

**结论**：在熟悉题型上正确，并不能证明能迁移到陌生表征、情境或问题结构；迁移需要独立测量。

- 证据等级：`学术共识`
- Askora 当前适用：最高

**Askora 设计含义**：

稳定掌握与迁移掌握分层：

```text
稳定掌握 ≠ 迁移掌握
```

至少区分：

- 同构近迁移；
- 表面变化；
- 表征变化；
- 跨情境/跨领域远迁移。

4.4 负责产生迁移测量结果，4.3 决定如何更新 learner state。

## 4. 对 Askora 的公共教学科学约束

`Askora 设计选择`

1. **最终目标**：独立完成、延迟保持、迁移；即时正确率只作为中间证据。
2. **证据权重必须区分提示暴露**：完整答案后复述 < 强提示 < 轻提示 < 无提示 < 延迟无提示 < 陌生迁移。
3. **教学强度必须可撤除**：支架不能成为永久默认。
4. **错误是诊断证据，不是惩罚信号**：先判断缺知识、误解、执行错、提取失败还是迁移失败。
5. **计划器同时安排新学、提取、间隔复习和迁移**，不能只推进内容完成率。
6. **学习效果实验不得只看点击、时长、满意度**。
7. **不把任何单一教育理论编码成绝对规则**；对条件敏感的策略进入候选集并经实验验证。

## 5. 重要局限

- 许多教育研究来自课堂、实验室或特定学科，不能直接等比例外推到个人 AI Tutor。
- 平均效应不能代替个体效果；个性化策略需要在线验证。
- 学习科学提供的是约束与目标，不自动给出具体软件算法。
- “让学习者更投入”与“让学习者学得更好”不是同一目标。

## 7. 证据缺口

- AI 对话式 Tutor 中“苏格拉底追问”相对其他策略的稳定因果效应仍不足以做全局默认策略。
- 不同知识类型（事实、概念、程序、开放式推理）的最优复习模型仍需 Askora 自建数据验证。
- LLM 自动估计认知负荷、挫败感和元认知状态的可靠性证据不足，应作为低置信度推断而非事实。
