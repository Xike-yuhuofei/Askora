林
为什么做复杂题目时，我总是一边做一边就忘了前面几步？是我的记忆力比别人差吗？
14:02
A

这通常不是长期记忆力的问题，而是工作记忆容量在复杂任务中被占满的结果。做难题时每一步的中间结果都会暂存在工作记忆里，一旦超出容量，前面的信息就会丢失，于是你会觉得“忘了”。

所以问题不在于“记不住”，而在于任务同时要求你保存的中间状态太多。接下来我们先把这个概念弄清楚，再用一段原文验证，最后做一次理解检查。

关键概念
工作记忆　Working Memory
人在执行认知任务时，临时保存并操作信息的系统。它容量有限，通常只能同时处理约 4–7 个信息组块。
已加入复习
原文
Working memory has limited capacity, and this capacity must be shared between the storage of information and the mental processes required to transform that information.
· §Working Memory

这解释了更关键的一点：复杂任务不仅要求你记住中间状态，还要求你在记住的同时不断变换这些信息——两者会竞争同一份有限容量。中间状态越多，留给“思考”的空间就越少。
